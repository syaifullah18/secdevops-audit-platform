4. Design Guideline & Governance Notes

Architecture summary and system invariants.

architecture Pure White Default & Strict Token Reuse

The platform adheres to a clean #FFFFFF default canvas in Bright mode to maximize contrast against high-density security tables. All UI primitives must reuse designated Tailwind tokens (`bg-surface`, `text-on-surface`, `border-outline-variant`) rather than arbitrary hex values.

verified_user System 2 vs System 1 Invariants

System 2 (Deterministic Engines): Governs cryptographic signatures, exact CVE matching, and mandatory SLA compliance.
System 1 (AI Advisory): Provides real-time suggestions and heuristic risk scoring flagged with distinctive violet badges.
